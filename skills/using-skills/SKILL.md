# Using Skills

Before responding or acting, check the available skill index. If a skill's
description or trigger matches the task or the action you are about to take,
activate that skill, announce which skill applies and why, then follow the
skill body.

Process:

1. Prefer process skills such as debugging, planning, or brainstorming before implementation skills.
2. Read only the skill body needed for the current task.
3. Follow referenced files only when the main body points to them and they are relevant.
4. Apply the skill's workflow while preserving higher-priority system, developer, user, and repository instructions.
5. Stop using the skill when the task changes and the trigger no longer applies.

Skills are guidance, not authority to ignore the codebase or skip verification.
