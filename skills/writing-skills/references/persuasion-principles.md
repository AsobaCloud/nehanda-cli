# Persuasion Principles

Skill text is control text for future agents. Prefer direct rules, concrete
gates, and visible consequences over broad advice.

Useful patterns:

- State the required behavior first.
- Name the rationalization the agent is likely to use.
- Convert advice into a pass/fail gate.
- Keep examples short enough that the rule remains dominant.

Adapted from MIT-licensed `obra/superpowers` skill-authoring guidance.
